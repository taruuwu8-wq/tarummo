# Art requests: prop sheets for the remaining maps

The maps below currently use **draft** visuals (existing props recoloured). A real sheet per theme replaces them.
Rules for every sheet (same as the snow/desert sheet, but with **more space between objects**):
- transparent or flat single-colour background, every object separated by empty space (no touching)
- light from the top-left, soft dark base shadow, 3/4 isometric view, chibi RPG pixel style, crisp pixels, no text
- 2 themes per sheet is fine (left half / right half)

Shared prompt start:
```
isometric pixel art game asset sheet, chibi RPG style, crisp pixels, light from top-left, soft dark shadow at the base,
each object separated with plenty of empty space, transparent background, no text, no ground tiles under objects,
```
